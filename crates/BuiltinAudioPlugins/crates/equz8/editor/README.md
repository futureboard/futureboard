# EQUZ8 Editor

Embedded CEF editor for the built-in EQUZ8 dynamic EQ.

Visual language follows **MixStation** (Futureboard graphite tokens, Mona Sans,
Phosphor icons, portalled preset popover) with a **Pro-Q 4** graph stage and
**Serum-ish** metallic knobs.

```bash
bun install
bun run build
```

Assets are embedded by `equz8` `build.rs` via `builtin_ui_embed`.
